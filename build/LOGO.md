# Council / 群策

Concept: four independent conversation units gather around one shared insight. The four speech bubbles are peers; the amber center is the answer produced by their discussion.

Visual reference: Tetris desktop project's warm ivory tile, charcoal rounded modules and restrained amber accent. Council uses a distinct radial discussion symbol, not the Tetris letter or selection outline.

Colors: ivory #FAF9F5, charcoal #343536, amber #F5B544, guide dots #B7B3AA.

Source: scripts/generate-icons.cjs. Run npm run icons to regenerate SVG, PNG and the 16/24/32/48/64/128/256px Windows ICO. The compact SVG in the renderer omits the tile's decorative dots for legibility.
